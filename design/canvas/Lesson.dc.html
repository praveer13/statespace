Negate, then search

You want to know whether a transfer can ever leave the source balance negative. A solver doesn't prove "for all"; it searches for "there exists". So you hand it the bad outcome and ask for a witness. If one exists, you have a counterexample. If none exists, the property holds — for exactly the constraints you wrote down.

Margin note Validity of P is the same question as unsatisfiability of ¬P. Every check in this course, from Z3 to TLC, is that move in different clothes.

s.add(a >= 0, b >= 0, amount > 0)   # the world we assume
s.add(a - amount < 0)                 # the bad outcome, asserted
s.check()
