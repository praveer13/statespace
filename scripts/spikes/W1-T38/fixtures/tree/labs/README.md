# statespace-lab: how the labs work

This is a fixture for the lessons gate: a manual for the lab system that passes the copy rules.

A lab is a staged build on your own machine. Every result names who ran the check, and the interface shows one of three badges: *re-checked here*, *reported from your machine* and *self-assessed*.

*Design-notes cross-reference.* The design notes call the first path Lane A and the second Lane B. The interface and the lessons use the badge words, and so does this file.

Help is a ladder with a gate in front of it. The next hint opens after a teach-back of at least 12 words, and you can open any rung at any time.
