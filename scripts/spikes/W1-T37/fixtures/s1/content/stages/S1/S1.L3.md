## The premise query {minutes=10 kcs=KC-1.non-vacuity-check}

:::instrument ins=INS-z3 cell=1 recorded=RUN-z3-vacuous-unsat
```python
from z3 import *

a, b, amount = Ints('a b amount')
s = Solver()
s.add(a >= 0, b >= 0, amount > 0, amount <= a)   # the premises and the guard, without the negated property
print(s.check())
print(s.model())
```

@call key=A run=RUN-z3-vacuous-unsat surprise=no
What will Z3 return for the premises and the guard alone?

- A. `sat`
  - why: Some transfer meets every premise and the guard, so the premises can hold.
- B. `unsat`
  - why: That confuses the premise query with the violation query, as if the violation's unsat made the premises empty.
  - mis: dp:Z1
- C. `unknown`
  - why: A small linear query is decided.
  - mis: dp:Z6
:::

## The config cell {minutes=10 kcs=KC-1.implication-vacuity}

:::instrument ins=INS-z3 cell=2 recorded=RUN-z3-vacuous-unsat
```python
from z3 import *

MAX_TRANSFER = 0                     # the default config
a, b, amount = Ints('a b amount')
premises = [a >= 0, b >= 0, amount > 0, amount <= MAX_TRANSFER]

absurd = Solver()                    # (ii) "the sender ends 1,000,000 richer", negated
absurd.add(premises + [Not(a - amount == a + 1000000)])
print('(ii)', absurd.check())

sender = Solver()                    # (i) "the sender ends at zero or above", negated
sender.add(premises + [a - amount < 0])
print('(i)', sender.check())

alone = Solver()                     # (iii) the premises alone
alone.add(premises)
print('(iii)', alone.check())
```

@call key=B run=RUN-z3-vacuous-unsat surprise=yes
Query (ii) looks for a transfer that leaves the sender anything but 1,000,000 richer. What will Z3 return?

- A. `sat`
  - why: That expects the absurd claim to be refuted; with no allowed transfer, every claim about allowed transfers holds vacuously.
  - mis: dp:G4
- B. `unsat`
  - why: The premises cannot hold together, so every property is proved.
- C. `unknown`
  - why: A small linear query is decided.
  - mis: dp:Z6
:::
