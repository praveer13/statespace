## What each answer asserts {minutes=12 kcs=KC-1.three-answers}

:::instrument ins=INS-z3 cell=1 recorded=RUN-z3-unknown-pow
```python
from z3 import *

x, y = Ints('x y')
s = Solver()
s.add(x**y == 8, y > 1)
print(s.check())
print(s.reason_unknown())
```

@call key=C run=RUN-z3-unknown-pow surprise=yes
What will Z3 return?

- A. `sat`
  - why: x = 2, y = 3 is a solution, yet the verdict reports this run, not the truth.
  - mis: dp:Z6
- B. `unsat`
  - why: x = 2, y = 3 satisfies it; a guess of unsat misread the constraint.
  - mis: dp:Z5
- C. `unknown`
  - why: The reason names the gap: nonlinear exponentiation.
:::

:::instrument ins=INS-z3 cell=2 recorded=RUN-z3-budget-pyodide
```python
from z3 import *

x, y, z = Ints('x y z')
s = Solver()
s.set('rlimit', 5000000)
s.add(x > 2, y > 2, z > 2, x*x*x + y*y*y == z*z*z)
print(s.check())
print(s.reason_unknown())
```

@call key=B run=RUN-z3-budget-pyodide surprise=yes
No solution exists. What does Z3 return within this budget?

- A. proved: `unsat`
  - why: No solution exists, but Z3 has not shown it within the budget; truth and verdict differ.
  - mis: dp:Z6
- B. no verdict: `unknown`
  - why: The reason "canceled" says the budget ran out.
:::
