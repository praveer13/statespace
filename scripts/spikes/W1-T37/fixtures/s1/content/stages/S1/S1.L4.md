## Conservation {minutes=10 kcs=KC-1.two-state-property}

:::instrument ins=INS-z3 cell=1 recorded=RUN-z3-conservation-noguard
```python
from z3 import *

a, b, amount = Ints('a b amount')
s = Solver()
s.add(Not((a - amount) + (b + amount) == a + b))   # conservation of the plain transfer, negated
print(s.check())
```

@call key=A run=RUN-z3-conservation-noguard surprise=yes
Does the plain transfer, with no guard, conserve the total?

- A. proved
  - why: Conservation needs no guard: the debit and the credit cancel for every input.
- B. counterexample
  - why: Conservation is not non-negativity; "money is safe" was never unpacked into one property.
  - mis: dp:G6
- C. `unknown`
  - why: A small linear query is decided.
  - mis: dp:Z6

## Capturing a hold twice {minutes=12 kcs=KC-1.two-state-property}

:::instrument ins=INS-z3 cell=2 recorded=RUN-z3-double-capture
```python
from z3 import *

Status, (HELD, CAPTURED) = EnumSort('Status', ['HELD', 'CAPTURED'])
h = Int('h')                                    # the amount of the hold under test

def state(sfx):
    return {'avail': Int('avail' + sfx), 'held': Int('held' + sfx), 'merchant': Int('merchant' + sfx),
            'status': Const('status' + sfx, Status)}

def capture(x, y, guard=None):                  # one capture, a relation between S and S'
    body = And(y['held'] == x['held'] - h, y['merchant'] == x['merchant'] + h,
               y['avail'] == x['avail'], y['status'] == CAPTURED)
    return body if guard is None else And(guard(x), body)

def query(formulas):
    s = Solver()
    s.add(formulas)
    return s.check()

S, S1, S2 = state(''), state('_p'), state('_pp')
total = lambda x: x['avail'] + x['held'] + x['merchant']
start = [S['avail'] >= 0, S['held'] >= 0, S['merchant'] >= 0, h > 0, S['held'] >= h, S['status'] == HELD]
twice = [capture(S, S1), capture(S1, S2)]       # the buggy capture, applied twice
gains_more = S2['merchant'] - S['merchant'] > h
patched = lambda x: x['held'] >= h              # the patch reads the pooled balance
fixed = lambda x: x['status'] == HELD           # the fix reads the hold's own status

print('(i) conservation', query(start + twice + [total(S2) != total(S)]))
print('(ii) at most once', query(start + twice + [gains_more]))
print('(iii) the patch', query(start + [capture(S, S1, patched), capture(S1, S2, patched), gains_more]))
print('(iv) the fix', query(start + [capture(S, S1, fixed), capture(S1, S2, fixed), gains_more]))
print('(v) one capture', query(start + [capture(S, S1, fixed)]))
```

@call key=B run=RUN-z3-double-capture surprise=yes
Query (i) asks whether the double capture breaks conservation of the total. What will Z3 return?

- A. conservation fails (`sat`)
  - why: The double capture lowers the held balance as it raises the merchant's.
  - mis: dp:O2
- B. conservation holds (`unsat`)
  - why: Each capture moves money from held to the merchant; it creates none.
- C. `unknown`
  - why: A small linear query is decided.
  - mis: dp:Z6
:::
