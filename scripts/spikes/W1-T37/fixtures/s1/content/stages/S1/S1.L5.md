## The sender at 64 bits {minutes=14 kcs=KC-1.encoding-is-the-claim}

:::instrument ins=INS-z3 cell=1 recorded=RUN-z3-bv64-negamt
```python
from z3 import *

A, B, X = BitVecs('A B X', 64)      # signed 64-bit balances and amount
s = Solver()
s.add(A >= 0, B >= 0, X <= A)       # the guard, and no X > 0
s.add(A - X < 0)                    # the sender ends below zero
print(s.check())
print(s.model())
```

@call key=A run=RUN-z3-bv64-negamt surprise=yes
Without amount > 0, can the sender end below zero at 64 bits?

- A. `sat`
  - why: Subtracting a negative amount is an addition, and at 64 bits that addition can overflow.
- B. `unsat`
  - why: Over Int a negative amount makes the sender richer, never poorer; at 64 bits it can wrap.
  - mis: dp:Z4
- C. `unknown`
  - why: Bit-vector queries of this size are decided.
  - mis: dp:Z6
:::

## The total at 64 bits {minutes=14 kcs=KC-1.encoding-is-the-claim}

:::instrument ins=INS-z3 cell=2 recorded=RUN-z3-bv64
```python
from z3 import *

A, B, X = BitVecs('A B X', 64)
s = Solver()
s.add(Not((A - X) + (B + X) == A + B))   # conservation modulo 2**64, negated
print(s.check())
```

@call key=A run=RUN-z3-bv64 surprise=yes
Does the total survive 64-bit arithmetic?

- A. proved
  - why: Arithmetic modulo 2**64 still cancels; a wrap moves no money in this sum.
- B. counterexample
  - why: A wrap in one term is undone by the other.
  - mis: dp:Z7
- C. `unknown`
  - why: Bit-vector queries of this size are decided.
  - mis: dp:Z6
:::

## Signed and unsigned {minutes=14 kcs=KC-1.encoding-is-the-claim}

:::instrument ins=INS-z3 cell=3 recorded=RUN-z3-bv64
```python
from z3 import *

A, X = BitVecs('A X', 64)
s = Solver()
s.add(UGT(X, 0), ULE(X, A))         # an unsigned guard
s.add(A - X < 0)                    # a signed property
print(s.check())
print(s.model())
```

@call key=A run=RUN-z3-bv64 surprise=moderate
The guard compares unsigned and the property signed. What will Z3 return?

- A. `sat`
  - why: The unsigned guard reads A's bits as a large number, while the signed property reads the same bits as negative.
- B. `unsat`
  - why: The guard and the property disagree about the state.
  - mis: dp:Z5
- C. `unknown`
  - why: Bit-vector queries of this size are decided.
  - mis: dp:Z6
:::
