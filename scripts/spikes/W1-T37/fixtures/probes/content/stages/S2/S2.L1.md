## Several queries in one SMT-LIB cell {minutes=10}

:::instrument ins=INS-z3 cell=1 recorded=RUN-z3-smtlib-tour
```smt2
(declare-const a Int)
(declare-const b Int)
(declare-const amount Int)
(assert (and (>= a 0) (>= b 0) (> amount 0)))
(assert (< (- a amount) 0))   ; the negated property
(check-sat)
(assert (<= amount a))        ; the guard
(check-sat)
```

@call key=A run=RUN-z3-smtlib-tour
What does the first check-sat print?

- A. `sat`
  - why: Without the guard, a transfer larger than the balance is allowed.
- B. `unsat`
  - why: The guard comes after the first query.
  - mis: dp:Z1

## Bit-vector optima {minutes=10}

:::instrument ins=INS-z3 cell=4 recorded=RUN-z3-bv64 call=false
```python
from z3 import *

B, X = BitVecs('B X', 64)
o = Optimize()
o.add(B >= 0, X > 0, B + X < 0)     # a signed overflow
o.minimize(X)
print(o.check())
```
:::

:::instrument ins=INS-z3 cell=5 recorded=RUN-z3-bv64
```python
from z3 import *

X = BitVec('X', 8)
o = Optimize()
o.add(UGT(X, 5))
o.minimize(X)
print(o.check(), o.model())
```

@call key=A run=RUN-z3-bv64
What is the smallest X the solver finds?

- A. `6`
  - why: The smallest 8-bit value above 5.
- B. `5`
  - why: UGT is strict.
  - mis: dp:Z1
:::
