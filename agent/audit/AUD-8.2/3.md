**The requirement.** Every run of the simulator is a behavior of the Outbox spec (S8.L2): in particular the worker commits an intent before it sends it, and stores the provider's result before it acknowledges, so that no crash can lose a result the outbox already reports as done.

**Statement · Rust**

```
// sim/src/worker.rs: the worker's path for one command
pub fn submit(w: &mut Worker, c: &str) {
    w.begin();
    w.insert_command(c);
    w.insert_intent(c);
    w.commit(c);              // the command and its intent, one transaction
    w.arm_timer(c);
    w.dispatch(c);            // send the intent with its key
}

pub fn on_reply(w: &mut Worker, c: &str, reply: Reply) {
    w.receive(c, reply);
    w.persist(c);             // store the provider's result
    w.ack(c);                 // mark the intent done
}
```
