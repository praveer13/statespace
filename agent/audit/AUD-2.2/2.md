**The requirement.** Every call of transfer keeps the total of the two balances, and Lean's kernel has checked a proof of it that rests only on the standard axioms (propext, Quot.sound, Classical.choice).

**Statement · Lean**

```
structure Ledger where
  a : Int
  b : Int

def transfer (l : Ledger) (amt : Int) : Ledger :=
  if 0 < amt ∧ amt ≤ l.a then { a := l.a - amt, b := l.b + amt } else l

theorem transfer_conserves (l : Ledger) (amt : Int) :
    (transfer l amt).a + (transfer l amt).b = l.a + l.b
```
