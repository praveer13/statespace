**The requirement.** Every step the shipped code takes keeps the invariant: for every command the shipped checker accepts (HasType, that is typecheck c = none) and every successful step of the shipped evaluator exec from a state with no negative balance, the new state has no negative balance either. The theorem must speak of those commands and those steps.

**Statement · Lean**

```
-- Ledger.lean: the shipped evaluator
def exec : Cmd → State → Except String State
  | .transfer x y n, s => if n ≤ s x then .ok (post s x y n) else .error "guard-failed"

-- Ledger.lean: the step invariant
def execStrict : Cmd → State → Except String State
  | .transfer x y n, s => if n < s x then .ok (post s x y n) else .error "guard-failed"

theorem step_preserves_inv (c : Cmd) (s s' : State) :
    HasType c → NonNeg s → execStrict c s = .ok s' → NonNeg s'
```
