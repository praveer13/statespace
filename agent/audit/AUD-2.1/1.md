## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Refunds never overdraw anyone; proved.”

**The requirement.** If every balance is at zero or above before a refund of a non-negative amount, every balance is at zero or above after it: the customer's, the merchant's and every other account's.

**Statement · Lean**

```
def NonNeg (s : State) : Prop := ∀ j, 0 ≤ s.balance j

def refund (s : State) (p : PaymentId) (amt : Int) : State :=
  if amt ≤ s.balance (s.payments p).merchant then
    { s with balance := fun j =>
        if j = (s.payments p).merchant then s.balance j - amt
        else if j = (s.payments p).customer then s.balance j + amt
        else s.balance j }
  else s

theorem refund_nonneg (s : State) (p : PaymentId) (amt : Int)
    (hInv : NonNeg s) (hPos : 0 ≤ amt) :
    NonNeg (refund s p amt)
```
