## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Noninterference proved for the document view.”

**The requirement.** A client of an Acme user cannot tell apart two worlds that differ only in another tenant's private documents, by anything the response carries: its JSON body, its result count, its status code.

**Statement · Z3Py**

```
def search(W):                                       # Search(frank, "layoffs")
    hits  = count([And(e, r, m) for e, r, m in W])   # readable matches: the JSON body
    total = count([And(e, m) for e, r, m in W])      # the result count
    return hits, total

def observe(hits, total):                            # what the proof compares
    return [hits]

L, R = world('L'), world('R')                        # three document slots each
s = Solver()
s.add(rel(L, R))                                     # Rel: the worlds agree on what Acme may know
s.add(Or([a != b for a, b in zip(observe(*search(L)), observe(*search(R)))]))
print(s.check())
```
