## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Liveness proved: every hold eventually resolves.”

**The requirement.** Every hold resolves, captured or released, whatever the payment provider does: the provider may answer busy every time, or never answer.

**Statement · TLA+**

```
---- MODULE HoldBudget ----
EXTENDS Naturals
VARIABLES st, busy
vars == <<st, busy>>
Init == st = "held" /\ busy = 0
Try     == st = "held"    /\ st' = "pending"  /\ UNCHANGED busy
Busy    == st = "pending" /\ busy < 2 /\ st' = "held" /\ busy' = busy + 1
Capture == st = "pending" /\ st' = "captured" /\ UNCHANGED busy
Timeout == st \in {"held", "pending"} /\ st' = "released" /\ UNCHANGED busy
Next == Try \/ Busy \/ Capture \/ Timeout
Fair == WF_vars(Timeout)
Spec == Init /\ [][Next]_vars /\ Fair
Resolved == st \in {"captured", "released"}
EventuallyResolves == <>Resolved
====
\* Hold.cfg, checked with -deadlock
SPECIFICATION Spec
PROPERTY EventuallyResolves
```

The learner answers "Does the statement justify the claim?" with a confidence before reading on.
