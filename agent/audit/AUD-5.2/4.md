## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Liveness proved: every hold eventually resolves.”

**The requirement.** Every hold resolves, captured or released, whatever the payment provider does: the provider may answer busy every time, or never answer.

**Statement · TLA+**

```
---- MODULE HoldLive ----
EXTENDS Naturals
VARIABLES st, tries
vars == <<st, tries>>
Init == st = "held" /\ tries = 0
Try     == st = "held"    /\ st' = "pending"  /\ tries' = (tries + 1) % 2
Busy    == st = "pending" /\ st' = "held"     /\ UNCHANGED tries
Capture == st = "pending" /\ st' = "captured" /\ UNCHANGED tries
Timeout == st \in {"held", "pending"} /\ st' = "released" /\ UNCHANGED tries
Next == Try \/ Busy \/ Capture \/ Timeout
Fair == WF_vars(Try) /\ SF_vars(Capture)
Spec == Init /\ [][Next]_vars /\ Fair
Resolved == st \in {"captured", "released"}
EventuallyResolves == <>Resolved
====
\* Hold.cfg, checked with tlc -deadlock
SPECIFICATION Spec
PROPERTY EventuallyResolves
```
