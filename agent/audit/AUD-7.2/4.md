## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “No tenant can ever observe any change in another tenant.”

**The requirement.** Acme sees nothing of Birch's beyond what the product releases on purpose: the title and body of each document Birch shares with Acme, as Birch edits them, for as long as the share lasts; and the platform-wide document count on every tenant's usage panel. Everything else of Birch's stays out of Acme's view.

**Statement · Z3Py**

```
def view_A(W):                                   # Acme's usage panel
    return [W.own_A, 1 + count(W.exists_B)]      # its document, and the platform-wide document count

def rel(L, R):                                   # what Acme may know
    return And(L.own_A == R.own_A, count(L.exists_B) == count(R.exists_B))   # DCL-7.2: the platform-wide count

L, R = Usage('L'), Usage('R')                    # Acme's document; two of Birch's private ones
s = Solver()
s.add(rel(L, R))
s.add(Or([a != b for a, b in zip(view_A(L), view_A(R))]))
print(s.check())
```
