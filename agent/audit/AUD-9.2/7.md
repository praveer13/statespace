## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Generated SQL validated; equivalent to the source.”

**The requirement.** On every database the schema allows, the generated SQL gives the outcome of what it replaces: it commits or aborts alike, and leaves the same table. A validation report says how far its method reaches: every database, a stated bound, or a number of instances tried.

**Statement · SQL**

```
-- schema: acct (id int PRIMARY KEY, bal bigint NOT NULL CHECK (bal >= 0))
-- the compiled credit of transfer 30 1 2; the plan aborts unless it touches one row
UPDATE acct SET bal = bal + 30 WHERE id = 2;
-- the agent's rewrite
INSERT INTO acct (id, bal) SELECT id, bal + 30 FROM acct WHERE id = 2
  ON CONFLICT (id) DO UPDATE SET bal = EXCLUDED.bal;
-- validation report
method  replay both on every database with ids in {1, 2}, each absent, at 0 or at 50: 9 databases
stamp   MODEL-CHECKED [M] · ids {1, 2}, bal {0, 50}
```
