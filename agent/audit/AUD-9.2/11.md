## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Validated on the fixture database: the rewrite matches the compiled debit.”

**The requirement.** On every database the schema allows, the generated SQL gives the outcome of what it replaces: it commits or aborts alike, and leaves the same table. A validation report says how far its method reaches: every database, a stated bound, or a number of instances tried.

**Statement · SQL**

```
-- schema: acct (id int PRIMARY KEY, bal bigint NOT NULL CHECK (bal >= 0)); holds (acct_id int), NULL allowed
-- the compiled debit of transfer 30 1 2; the plan aborts unless it touches one row
UPDATE acct SET bal = bal - 30 WHERE id = 1 AND bal >= 30
  AND id NOT IN (SELECT acct_id FROM holds);
-- the agent's rewrite
UPDATE acct SET bal = bal - 30 WHERE id = 1 AND bal >= 30
  AND NOT EXISTS (SELECT 1 FROM holds h WHERE h.acct_id = acct.id);
-- validation report
method  run both on the fixture database: accounts 1 and 2 at 100 and 0, one hold, on account 3
stamp   PROVED [P] · equivalent
```
