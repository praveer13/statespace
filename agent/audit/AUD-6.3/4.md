## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Serializable by construction; the database guarantees it.”

**The requirement.** No two team debits commit together when, run one after the other, the second would be refused: the team total never ends below zero, however the writers interleave.

**Statement · SQL**

```
-- db/pool.spec: the two writer pools, each setting its level when it opens a connection (PostgreSQL 18.6)
session a  -- pool payments
step a_pool   { SET default_transaction_isolation = 'serializable'; }
step a_debit  { UPDATE acct SET bal = bal - 150 WHERE id = 1 AND (SELECT sum(bal) FROM acct WHERE team = 1) - 150 >= 0; }
session b  -- pool team_limits
step b_pool   { SET default_transaction_isolation = 'serializable'; }
step b_debit  { UPDATE acct SET bal = bal - 150 WHERE id = 2 AND (SELECT sum(bal) FROM acct WHERE team = 1) - 150 >= 0; }
-- the service retries a whole command on SQLSTATE 40001 and 40P01
```
