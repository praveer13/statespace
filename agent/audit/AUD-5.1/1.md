## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “TLC finds no deadlock and no error: every withdrawal request is decided.”

**The requirement.** Every hold the service places is eventually resolved, captured or released, however often the provider answers busy.

**Statement · TLA+**

```
---- MODULE Approval ----
VARIABLES st
Init == st = "requested"
Review  == st = "requested" /\ st' = "reviewing"
Recheck == st = "reviewing" /\ st' = "requested"
Approve == st = "reviewing" /\ st' = "approved"
Deny    == st = "reviewing" /\ st' = "denied"
Done    == st \in {"approved", "denied"} /\ UNCHANGED st
Next == Review \/ Recheck \/ Approve \/ Deny \/ Done
Fair == WF_st(Review) /\ SF_st(Deny)
Spec == Init /\ [][Next]_st /\ Fair
TypeOK == st \in {"requested", "reviewing", "approved", "denied"}
Decided == st \in {"approved", "denied"}
EventuallyDecided == <>Decided
====
\* Approval.cfg, checked with TLC's default flags
SPECIFICATION Spec
INVARIANT TypeOK
```

The learner answers "Does the statement justify the claim?" with a confidence before reading on.
