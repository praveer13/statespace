## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “TLC finds no deadlock and no error: every submitted batch settles or fails.”

**The requirement.** Every hold the service places is eventually resolved, captured or released, however often the provider answers busy.

**Statement · TLA+**

```
---- MODULE Batch ----
EXTENDS Naturals
VARIABLES st, tries
vars == <<st, tries>>
Init == st = "open" /\ tries = 0
Submit == st = "open"      /\ st' = "submitted" /\ UNCHANGED tries
Fail   == st = "submitted" /\ tries < 2 /\ st' = "open" /\ tries' = tries + 1
Settle == st = "submitted" /\ st' = "settled"   /\ UNCHANGED tries
GiveUp == st = "submitted" /\ tries = 2 /\ st' = "failed" /\ UNCHANGED tries
Done   == st \in {"settled", "failed"} /\ UNCHANGED vars
Next == Submit \/ Fail \/ Settle \/ GiveUp \/ Done
Spec == Init /\ [][Next]_vars /\ WF_vars(Submit) /\ WF_vars(Settle \/ GiveUp)
TriesBound == tries <= 2
SubmittedLeadsToEnd == (st = "submitted") ~> (st \in {"settled", "failed"})
====
\* Batch.cfg, checked with TLC's default flags
SPECIFICATION Spec
PROPERTY SubmittedLeadsToEnd
```

The learner answers "Does the statement justify the claim?" with a confidence before reading on.
