## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “TLC finds no deadlock, so every refund request is answered.”

**The requirement.** Every hold the service places is eventually resolved, captured or released, however often the provider answers busy.

**Statement · TLA+**

```
---- MODULE RefundAsk ----
EXTENDS Naturals
VARIABLES st, n
vars == <<st, n>>
Init == st = "open" /\ n = 0
Ask    == st = "open"  /\ st' = "asked" /\ UNCHANGED n
Info   == st = "asked" /\ n < 3 /\ st' = "open" /\ n' = n + 1
Grant  == st = "asked" /\ st' = "granted" /\ UNCHANGED n
Refuse == st = "asked" /\ st' = "refused" /\ UNCHANGED n
Done   == st \in {"granted", "refused"} /\ UNCHANGED vars
Next == Ask \/ Info \/ Grant \/ Refuse \/ Done
Spec == Init /\ [][Next]_vars /\ WF_vars(Ask) /\ WF_vars(Grant \/ Refuse)
Answered == <>(st \in {"granted", "refused"})
====
\* RefundAsk.cfg, checked with TLC's default flags
SPECIFICATION Spec
CHECK_DEADLOCK TRUE
```
