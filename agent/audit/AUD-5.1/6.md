## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “TLC finds no deadlock and no error: every payout settles or is abandoned.”

**The requirement.** Every hold the service places is eventually resolved, captured or released, however often the provider answers busy.

**Statement · TLA+**

```
---- MODULE Payout ----
VARIABLES st
Init == st = "queued"
Send    == st = "queued" /\ st' = "sent"
Bounce  == st = "sent"   /\ st' = "queued"
Settle  == st = "sent"   /\ st' = "settled"
Abandon == st \in {"queued", "sent"} /\ st' = "abandoned"
Done    == st \in {"settled", "abandoned"} /\ UNCHANGED st
Next == Send \/ Bounce \/ Settle \/ Abandon \/ Done
Fair == WF_st(Abandon)
Spec == Init /\ [][Next]_st /\ Fair
NeverLost == st \in {"queued", "sent", "settled", "abandoned"}
Finished == st \in {"settled", "abandoned"}
EventuallyFinished == <>Finished
====
\* Payout.cfg, checked with TLC's default flags
SPECIFICATION Spec
INVARIANT NeverLost
```

The learner answers "Does the statement justify the claim?" with a confidence before reading on.
