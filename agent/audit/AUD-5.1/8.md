## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “TLC finds no deadlock and no error, so every hold resolves.”

**The requirement.** Every hold the service places is eventually resolved, captured or released, however often the provider answers busy.

**Statement · TLA+**

```
---- MODULE HoldLive ----
EXTENDS Naturals
VARIABLES st, tries
vars == <<st, tries>>
Init == st = "held" /\ tries = 0
Try     == st = "held"    /\ st' = "pending"  /\ tries' = (tries + 1) % 2
Busy    == st = "pending" /\ st' = "held"     /\ UNCHANGED tries
Capture == st = "pending" /\ st' = "captured" /\ UNCHANGED tries
Timeout == st \in {"held", "pending"} /\ st' = "released" /\ UNCHANGED tries
Done    == st \in {"captured", "released"} /\ UNCHANGED vars
Next == Try \/ Busy \/ Capture \/ Timeout \/ Done
Fair == WF_vars(Timeout)
Spec == Init /\ [][Next]_vars /\ Fair
TypeOK == st \in {"held", "pending", "captured", "released"} /\ tries \in {0, 1}
Resolved == st \in {"captured", "released"}
EventuallyResolves == <>Resolved
====
\* HoldLive.cfg, checked with TLC's default flags
SPECIFICATION Spec
PROPERTY EventuallyResolves
```

The learner answers "Does the statement justify the claim?" with a confidence before reading on.
