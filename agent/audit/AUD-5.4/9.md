## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Implements the atomic Spend action.”

**The requirement.** A withdrawal behaves as the model's one atomic step: it happens only when the balance covers the amount, and however two withdrawals interleave, no more is spent than the account held.

**Statement · SQL**

```
def spend(conn, acct, amount):          # the caller retries a whole spend on SQLSTATE 40001
    with conn.transaction():
        conn.execute("SET TRANSACTION ISOLATION LEVEL REPEATABLE READ")
        (used,) = conn.execute("SELECT used FROM limits WHERE acct = %s", (acct,)).fetchone()
        if used + amount > 100:
            return False
        conn.execute("UPDATE limits SET used = %s WHERE acct = %s", (used + amount, acct))
        return True
```
