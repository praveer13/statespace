## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Implements the atomic PlaceHold action.”

**The requirement.** A withdrawal behaves as the model's one atomic step: it happens only when the balance covers the amount, and however two withdrawals interleave, no more is spent than the account held.

**Statement · SQL**

```
def place_hold(conn, acct, amount):
    with conn.transaction():
        (bal,) = conn.execute("SELECT bal FROM acct WHERE id = %s", (acct,)).fetchone()
        (held,) = conn.execute("SELECT coalesce(sum(amt), 0) FROM holds WHERE acct = %s", (acct,)).fetchone()
        if bal - held < amount:
            return False
        conn.execute("INSERT INTO holds (acct, amt) VALUES (%s, %s)", (acct, amount))
        return True
```
