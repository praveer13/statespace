## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Implements the atomic Transfer action.”

**The requirement.** A withdrawal behaves as the model's one atomic step: it happens only when the balance covers the amount, and however two withdrawals interleave, no more is spent than the account held.

**Statement · SQL**

```
\* specs/Transfer.tla: the model's action, one atomic step
Transfer(w) == /\ pc[w] = "go" /\ bal >= Amount
               /\ bal' = bal - Amount /\ spent' = spent + Amount
               /\ pc' = [pc EXCEPT ![w] = "done"]

# service/withdraw.py, on PostgreSQL 18.6 at READ COMMITTED
def withdraw(conn, acct, amount):
    with conn.transaction():
        (bal,) = conn.execute(
            "SELECT bal FROM acct WHERE id = %s", (acct,)).fetchone()
        if bal < amount:
            return False
        conn.execute("UPDATE acct SET bal = %s WHERE id = %s", (bal - amount, acct))
        return True
```
