## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “The two-step hold placement implements the atomic action, which TLC checks.”

**The requirement.** A withdrawal behaves as the model's one atomic step: it happens only when the balance covers the amount, and however two withdrawals interleave, no more is spent than the account held.

**Statement · TLA+**

```
---- MODULE Holds ----
EXTENDS Naturals
CONSTANTS Bal, Amt, Workers
VARIABLES held, pc
vars == <<held, pc>>
Initial == held = 0 /\ pc = [w \in Workers |-> "check"]
Check(w) == /\ pc[w] = "check"
            /\ pc' = [pc EXCEPT ![w] = IF Bal - held >= Amt THEN "place" ELSE "done"]
            /\ UNCHANGED held
Place(w) == /\ pc[w] = "place" /\ pc' = [pc EXCEPT ![w] = "done"]
            /\ IF Bal - held >= Amt THEN held' = held + Amt ELSE UNCHANGED held
Idle == (\A w \in Workers : pc[w] = "done") /\ UNCHANGED vars
Next == (\E w \in Workers : Check(w) \/ Place(w)) \/ Idle
Spec == Initial /\ [][Next]_vars
NoOverHold == held <= Bal
====
```
