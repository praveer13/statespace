**Statement · Z3Py**

```
a, amount, rate, fee = Ints('a amount rate fee')
s = Solver()
s.set('rlimit', 20000)
s.add(a >= 0, amount > 0)
s.add(rate >= 0, rate <= 500)                    # the rate in basis points
s.add(fee * 10000 <= amount * rate)              # fee = floor(amount * rate / 10000)
s.add(amount * rate < fee * 10000 + 10000)
s.add(amount + fee <= a)                         # the guard: the sender covers amount and fee
s.add(a - amount - fee < 0)                      # the violation: the sender ends below zero

print(r, s.reason_unknown() if r == unknown else '')
```
