## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Z3 found a bug in Settle; fixed.”

**The requirement.** A fix answers a bug: a state the commands can reach from Init, from which one of them breaks the invariant. A satisfiable inductive step alone is not one. When its pre-state cannot be reached, the invariant needs strengthening, and the command stays as it is.

**Statement · Z3Py**

```
# Init: queued == 0, settled == 0 and total == 0. The invariant to keep: settled <= total.
def step(s, t, n):
    (queued, settled, total), (queued2, settled2, total2) = s, t
    return And(n > 0, Or(
        And(queued2 == queued + n, total2 == total + n, settled2 == settled),            # Enqueue(n)
        And(n <= queued, queued2 == queued - n, settled2 == settled + n, total2 == total),  # Settle(n)
        And(n <= settled, settled2 == settled - n, queued2 == queued + 2 * n, total2 == total)))  # Requeue(n)
```
