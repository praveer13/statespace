## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Z3 found a bug in Refund; fixed.”

**The requirement.** A fix answers a bug: a state the commands can reach from Init, from which one of them breaks the invariant. A satisfiable inductive step alone is not one. When its pre-state cannot be reached, the invariant needs strengthening, and the command stays as it is.

**Statement · Z3Py**

```
# Init: cust >= 0, merch == 0 and paid == 0. The invariant to keep: merch >= 0.
def step(s, t, n):
    (cust, merch, paid), (cust2, merch2, paid2) = s, t
    return And(n > 0, Or(
        And(n <= cust, cust2 == cust - n, merch2 == merch + n, paid2 == paid + n),   # Pay(n)
        And(n <= paid, cust2 == cust + n, merch2 == merch - n, paid2 == paid - n),   # Refund(n)
        And(n <= merch - paid, cust2 == cust, merch2 == merch - n, paid2 == paid)))  # Payout(n)

# The inductive step for merch >= 0
q = Solver()
q.add(merch >= 0, step((cust, merch, paid), (cust2, merch2, paid2), n), merch2 < 0)
```
