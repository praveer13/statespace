## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Z3 found a bug in Capture; fixed.”

**The requirement.** A fix answers a bug: a state the commands can reach from Init, from which one of them breaks the invariant. A satisfiable inductive step alone is not one. When its pre-state cannot be reached, the invariant needs strengthening, and the command stays as it is.

**Statement · Z3Py**

```
# Init: bal >= 0 and held == 0. The invariant to keep: bal >= 0.
def step(s, t, n):                               # the agent's commands: one step from s to t
    (bal, held), (bal2, held2) = s, t
    return And(n > 0, Or(
        And(n <= bal - held, held2 == held + n, bal2 == bal),    # Hold(n)
        And(n <= held, held2 == held - n, bal2 == bal - n),      # Capture(n)
        And(n <= held, held2 == held - n, bal2 == bal)))         # Release(n)

bal, held, bal2, held2, n = Ints('bal held bal2 held2 n')

# The inductive step for bal >= 0: from any state that meets it, can one step break it?
q = Solver()
q.add(bal >= 0, step((bal, held), (bal2, held2), n), bal2 < 0)
print('step of bal >= 0:', q.check())
m = q.model()
print('  the pre-state has held above bal:', m[held].as_long() > m[bal].as_long())
```
