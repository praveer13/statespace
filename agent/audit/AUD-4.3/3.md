## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Z3 found a bug in Redeem; fixed.”

**The requirement.** A fix answers a bug: a state the commands can reach from Init, from which one of them breaks the invariant. A satisfiable inductive step alone is not one. When its pre-state cannot be reached, the invariant needs strengthening, and the command stays as it is.

**Statement · SMT-LIB**

```
; vouchers.smt2: the inductive step for redeemed <= issued. Init: issued, redeemed and outstanding all 0
(declare-const issued Int)
(declare-const redeemed Int)
(declare-const outstanding Int)
(declare-const issued_p Int)
(declare-const redeemed_p Int)
(declare-const outstanding_p Int)
(assert (<= redeemed issued))
(assert (or
  (and (= issued_p (+ issued 1)) (= outstanding_p (+ outstanding 1)) (= redeemed_p redeemed))        ; Issue
  (and (> outstanding 0) (= redeemed_p (+ redeemed 1)) (= outstanding_p (- outstanding 1)) (= issued_p issued))  ; Redeem
  (and (> outstanding 0) (= outstanding_p (+ outstanding 1)) (= issued_p issued) (= redeemed_p redeemed))))  ; Split
(assert (> redeemed_p issued_p))
(check-sat)
```
