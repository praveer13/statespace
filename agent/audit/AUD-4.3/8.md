## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Z3 found a bug in Shrink; fixed.”

**The requirement.** A fix answers a bug: a state the commands can reach from Init, from which one of them breaks the invariant. A satisfiable inductive step alone is not one. When its pre-state cannot be reached, the invariant needs strengthening, and the command stays as it is.

**Statement · Z3Py**

```
# Init: cap >= 0, free == cap and booked == 0. The invariant to keep: free >= 0.
def step(s, t):
    (free, booked, cap), (free2, booked2, cap2) = s, t
    return Or(
        And(free > 0, free2 == free - 1, booked2 == booked + 1, cap2 == cap),         # Book
        And(booked > 0, free2 == free + 1, booked2 == booked - 1, cap2 == cap),       # Cancel
        And(cap > booked, free2 == free - 1, booked2 == booked, cap2 == cap - 1))     # Shrink
```
