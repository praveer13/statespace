## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “Z3 found a bug in Refund on a dispute; fixed.”

**The requirement.** A fix answers a bug: a state the commands can reach from Init, from which one of them breaks the invariant. A satisfiable inductive step alone is not one. When its pre-state cannot be reached, the invariant needs strengthening, and the command stays as it is.

**Statement · Z3Py**

```
# Init: escrow >= 0 and disputed == 0. The invariant to keep: escrow >= 0.
def step(s, t, n):
    (escrow, disputed), (escrow2, disputed2) = s, t
    return And(n > 0, Or(
        And(n <= escrow - disputed, disputed2 == disputed + n, escrow2 == escrow),      # Dispute(n)
        And(n <= escrow - disputed, escrow2 == escrow - n, disputed2 == disputed),      # Release(n)
        And(n <= disputed, disputed2 == disputed - n, escrow2 == escrow - n)))          # Refund(n)
```
