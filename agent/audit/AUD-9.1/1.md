## Exercise 1 · Call the statement alone

The agent says (unreviewed):

> “The compiler preserves meaning; proved in Lean.”

**The requirement.** A client sees each command's outcome: whether it committed or aborted, the error code of an abort, and every balance after it. On every store and every amount, the compiled code gives the client what the source gives.

**Statement · Lean**

```
-- S9/Statement.lean. A store is (a1, a2); runS is the source transfer of amt from a1 to a2.
-- view s r: the balances after outcome r; an abort leaves the starting store s.
-- r.err? is r's error code, or none for a commit; (view s r).1 is a1's balance.
def obs (s : Store) (r : Outcome) : Option Err × Int := (r.err?, (view s r).1)

theorem preservation (amt : Int) (s : Store) (regs : Regs) :
    obs s (runT (compile amt) regs s) = obs s (runS amt s)
```
