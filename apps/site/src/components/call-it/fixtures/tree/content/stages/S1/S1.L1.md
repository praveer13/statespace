## Negating English {minutes=13 kcs=KC-1.quantifier-negation,KC-1.only-if-direction}

:::instrument ins=INS-z3 cell=1 recorded=RUN-z3-demorgan
The transfer has no guard. The query asks for both balances to end below zero at once.

```python
from z3 import *
a, b, amount = Ints('a b amount')
a2, b2 = a - amount, b + amount
s = Solver()
s.add(a >= 0, b >= 0, amount > 0)
s.add(And(a2 < 0, b2 < 0))
print(s.check())
```

@direction
Query asserts: the sender and the recipient both end below zero. `sat` means such a transfer exists.

@tap
the sender never ends below zero

@call key=B surprise=yes run=RUN-z3-demorgan
This query asks for `a2 < 0 and b2 < 0` on the unguarded transfer. What will Z3 return?

- A. `sat`
  - why: The transfer is unguarded, but this query needs both balances below zero at once, and the recipient only gains.
  - mis: dp:Z5
- B. `unsat`
  - why: No input satisfies it, so Z3 answers `unsat` {{run:RUN-z3-demorgan}}. The property is still violated: the right negation uses `or`, and it is `sat` in the same run.
- C. `unknown`
  - why: Three linear integer constraints are decided outright.
  - mis: dp:Z6

@after
That `unsat` was not safety. It answered the wrong question.
:::

:::instrument ins=INS-z3 cell=2 recorded=RUN-z3-optimize-min
The same unguarded transfer, searched with an objective: the smallest amount that overdraws the sender.

```python
from z3 import *
a, b, amount = Ints('a b amount')
o = Optimize()
o.add(a >= 0, b >= 0, amount > 0)
o.add(a - amount < 0)
o.minimize(amount)
print(o.check())
print(o.model())
```

@direction
Query asserts: an overdraft. Z3 minimizes `amount` over every witness.

@call key=A surprise=no run=RUN-z3-optimize-min
Z3 is asked for the overdraft with the smallest amount. What amount comes back?

- A. `1`
  - why: The minimizer chooses every variable, so it sets the sender's balance to 0 and the amount to 1 {{run:RUN-z3-optimize-min}}.
- B. `0`
  - why: The premise `amount > 0` excludes 0.
  - mis: dp:Z5
- C. One more than the sender's balance in the first witness
  - why: This treats the first witness's balance as fixed; it is one member of the class, not the bug.
  - mis: dp:Z3

@after
A minimal witness is one member of a class. Name the class, not the numbers.
:::
