## What each answer asserts {minutes=12 kcs=KC-1.three-answers,KC-1.unknown-fails-closed}

:::instrument ins=INS-z3 cell=1 recorded=RUN-z3-unknown-pow
A query over whole numbers with an exponent that is itself a variable.

```python
from z3 import *
x, y = Ints('x y')
s = Solver()
s.add(x**y == 8, y > 1)
print(s.check())
```

@direction
Query asserts: two whole numbers whose power is eight, with an exponent above one. `sat` means they exist.

@call key=C surprise=yes run=RUN-z3-unknown-pow
What will Z3 return?

- A. `sat`
  - why: A solution exists, but the verdict reports this run, not the truth.
  - mis: dp:Z6
- B. `unsat`
  - why: A solution exists, so a guess of `unsat` misread the constraint.
  - mis: dp:Z5
- C. `unknown`
  - why: Z3 gave up on the nonlinear exponent, and the reason line names the gap {{run:RUN-z3-unknown-pow}}.

@after
The same run decides a neighbouring query whose exponent is fixed.
:::

## A budget is part of the answer {minutes=12 kcs=KC-1.unknown-fails-closed}

:::instrument ins=INS-z3 cell=2 recorded=RUN-z3-budget-pyodide
A query with no solution, searched under `rlimit` 5000000.

```python
from z3 import *
x, y, z = Ints('x y z')
s = Solver()
s.set('rlimit', 5000000)
s.add(x > 2, y > 2, z > 2, x*x*x + y*y*y == z*z*z)
print(s.check())
```

@direction
Query asserts: three whole numbers above two whose cubes add up. `sat` means they exist.

@call key=B surprise=yes run=RUN-z3-budget-pyodide
This query has no solution, and Z3 runs it under `rlimit` 5000000. What does Z3 report?

- A. proved: `unsat`
  - why: No solution exists, but Z3 has not shown it within the budget; truth and verdict differ.
  - mis: dp:Z6
- B. no verdict: `unknown`
  - why: The run stopped on its budget and printed `unknown` with the reason "canceled" {{run:RUN-z3-budget-pyodide}}.

@after
A verdict at a stated `rlimit` can be run again; a stop is not an answer.
:::
