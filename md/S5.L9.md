## Lift it (14 min)

**Question** (before the segment):

TLC's inductive check passes at three workers. Which stamp?

- A. [P] for every N
- B. [T] · 1 instance
- C. [M] · three workers · inductive at N = 3

An invariant is *inductive* when `Init => Inv` and every step from any state in `Inv` stays in `Inv`: `Inv /\ Next => Inv'`. For the atomic transfer with `Init` 100 and `Amount` 80, `NoOverspend` alone is not inductive. From the unreachable state with `bal` 100 and `spent` 50, a Spend reaches `spent` 130. That state is a counterexample to induction (CTI), and the cure is a stronger invariant:

```tla
Inv == TypeOK /\ bal + spent = Init /\ bal >= 0 /\ spent >= 0
```

`Inv` is inductive and implies `NoOverspend`. On the unfixed transfer, `bal + spent = Init` fails at a reachable state, which is a real bug: fix the command (SP-5.1).

TLC can check this at fixed constants. Lamport's technique checks `Inv` as an invariant of `ISpec == Inv /\ [][Next]_vars`, with `TypeOK` leading `Inv` so that TLC can enumerate every initial state (run RUN-tlc-inductive). It works only for fixed, finite constants, so it earns [M] · constants · inductive at N = k, and nothing more. For every N, use Z3: make the workers an uninterpreted sort `W`, keep `pc` as an array from `W`, update it with `Store`, and leave `Init` and `Amount` symbolic. The query stays quantifier-free.

**Cell 1** (INS-z3)

Query asserts: `Init => Inv`, the inductive step `Inv /\ Step /\ ~Inv'`, and `Inv => NoOverspend`, with the number of workers left open. An unsatisfiable negated claim holds for every number of workers, and a satisfiable one would be a counterexample to induction. The last line is a premise witness.

```python
from z3 import *

W = DeclareSort('W')                          # any number of workers
Pc, (go, done) = EnumSort('Pc', ['go', 'done'])
Init, Amount = Ints('Init Amount')            # the constants stay symbolic
bal, spent, bal2, spent2 = Ints('bal spent bal2 spent2')
pc, pc2 = Array('pc', W, Pc), Array('pc2', W, Pc)
w = Const('w', W)                             # the worker that steps

consts = And(Init >= 0, Amount > 0)
init = And(bal == Init, spent == 0, pc == K(W, go))

def Inv(b, s):
    return And(b + s == Init, b >= 0, s >= 0)

step = And(pc[w] == go,
           If(bal >= Amount,
              And(bal2 == bal - Amount, spent2 == spent + Amount),
              And(bal2 == bal, spent2 == spent)),
           pc2 == Store(pc, w, done))

def ask(label, *claims):
    s = Solver()
    s.add(consts, *claims)
    print(label, s.check())

ask('Init => Inv         ', init, Not(Inv(bal, spent)))
ask('Inv & Step & ~Inv2  ', Inv(bal, spent), step, Not(Inv(bal2, spent2)))
ask('Inv => NoOverspend  ', Inv(bal, spent), Not(spent <= Init))
ask('premise: Inv & Step ', Inv(bal, spent), step)
```
