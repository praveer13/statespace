## Play, then read a proof (15 min)

**Question** (before the segment):

You prove a claim P(n) for every natural number n by induction. In the step from d to d + 1, what may you assume?

- A. P(d)
- B. P(d + 1)
- C. P(n) for every n
- D. Nothing, because P(0) already covers it

Induction proves a claim about every natural number without checking them one by one. The **base case** shows the claim for 0. The **step** shows that if the claim holds for some `d`, it holds for `d + 1`. Together they cover every `n`, like a row of dominoes: the first one falls, and each one knocks over the next.

The step is not circular. Its assumption is the claim for `d` and its goal is the claim for `d + 1`, so you are assuming one smaller case, not the thing you want to prove. The base case is not optional either: the step only says "if", and without a first case nothing ever falls.

[The Natural Number Game](https://adam.math.hhu.de/#/g/leanprover-community/NNG4) teaches this by making you rebuild arithmetic from `0` and `succ`, the successor. It is a separate site that runs in your browser, so the link leaves this course: the course does not see your progress and does not grade it. Play its first four worlds, Tutorial, Addition, Multiplication and Implication, as far as is useful. Plan three to five hours; that time belongs to the stage's build budget, not to this lesson. The game runs its own Lean version, so a few tactics behave differently on the Bench. If you would rather not leave the course, drawer D-08 holds a pinned fallback. Back here, read one induction in the shape you just practised. `credit2 k` is the total after `k` deposits of 2, and the theorem says it equals `k + k`. In the replay the `zero` case is the base case and the `succ` case is the step, with `ih` the claim for `k`. Make your call before the step is shown.

**Cell 1** (INS-goal-replay)

Replay shows: the proof of `credit2_eq`, one tactic at a time. The `zero` case is the base case; in the `succ` case, `ih` is the claim for `k`.

```lean
def credit2 : Nat → Nat
  | 0 => 0
  | k + 1 => credit2 k + 2

theorem credit2_eq (k : Nat) : credit2 k = k + k := by
  induction k with
  | zero => rfl
  | succ k ih =>
    unfold credit2
    rw [ih]
    omega
```

**Your call before the first run:**

Which fact closes the `k + 1` case after `credit2` is unfolded?

- B. `credit2 (k + 1) = (k + 1) + (k + 1)`
- C. `credit2 0 = 0`
- D. None: `rfl` closes it

**Question** (ends the segment):

`fees k` adds up `k` fees of 3, so `fees 0 = 0` and `fees (k + 1) = fees k + 3`. To prove `fees k = 3 * k` by induction on `k`, which fact does the `k + 1` case need?

- A. `fees (k + 1) = 3 * (k + 1)`
- B. `ih : fees k = 3 * k`
- C. `fees 0 = 0`
- D. `Nat.mul_comm`

## Exit (5 min)

**Question** (exit question):

`grow` doubles at each step: `grow 0 = 1` and `grow (k + 1) = grow k + grow k`. To prove `0 < grow k` by induction on `k`, which fact does the `k + 1` case need?

- A. `0 < grow (k + 1)`
- B. `grow 0 = 1`
- C. `ih : 0 < grow k`
- D. `Nat.add_comm`
