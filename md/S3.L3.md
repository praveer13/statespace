## Failure as a value (12 min)

A big-step evaluator takes a program, a call and a state, and returns the whole outcome at once. Mini-Plinth's returns `Except Err (State × Output × List Effect)`: either a named error, or a new state with an output and the effects to emit. Every failure is a value the caller can match on. That is what explicit errors means.

The evaluator checks in a fixed order, and the first check that fails decides the outcome:

1. The command exists, else `unknownCommand`.
2. The arguments decode, with positive amounts, else `badArgument`.
3. Every account argument exists, else `unknownAccount`.
4. A self-transfer is allowed or rejected, as your policy says.
5. The guard holds, else `guardFailed`.
6. A hold's checks pass, else `unknownHold` or `holdNotOpen`.
7. The postings run, then the effects and output are built.

The reference's default policy rejects a zero amount, allows a self-transfer, returns an error for a failed guard and lets balances grow without bound. S3.L7 makes each of those your decision. Here is the idea in a few lines.

```lean
abbrev State := List (String × Int)

def bal (s : State) (a : String) : Int := (s.lookup a).getD 0

def setBal (s : State) (a : String) (v : Int) : State :=
  s.map fun p => if p.1 = a then (a, v) else p

inductive Err where
  | badArgument (p : String)
  | unknownAccount (a : String)
  | guardFailed (c : String)
  deriving DecidableEq, Repr

/-- Debit, then credit, reading the updated state: a self-transfer changes nothing. -/
def post (s : State) (x y : String) (n : Int) : State :=
  let s₁ := setBal s x (bal s x - n)
  setBal s₁ y (bal s₁ y + n)

/-- Four of the reference's checks, as a function that returns every outcome as a value. -/
def transfer (s : State) (x y : String) (n : Int) : Except Err State :=
  if n ≤ 0 then .error (.badArgument "amount")
  else if (s.lookup x).isNone then .error (.unknownAccount x)
  else if (s.lookup y).isNone then .error (.unknownAccount y)
  else if bal s x < n then .error (.guardFailed "Transfer")
  else .ok (post s x y n)
```
