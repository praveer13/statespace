# D-14 · The wasm ABI for your Rust checks

> Draft: first-learner pass pending.

**Format.** Drawer: side material, always open, about 10 minutes.

**Objective.** Build a lab crate to a zero-import wasm module, run one check on a seed, read its per-check result, and stamp what a pass on seeds establishes.

## What runs where (2 min)

Your Rust compiles to a wasm module that imports nothing. The tab runs each check in a fresh instance of your module (the worker is replaced only after a timeout), on seeds drawn at grade time and under a time limit, and the result's badge reads *re-checked here*. A reference module earns nothing and says so.

## The protocol (3 min)

The module's interface comes from kernelspace, vendored at a pinned commit. In the family's design the module exports its memory, an interface version, allocation functions and one run entry that reads text lines (`list`, `only <id>`, `seed <n>`) and returns JSON. `list` names the checks and runs no learner code. `only <id>` returns the check's id, label, pass flag, message and seed. After a trap the module reports the panic message, and empty input runs every check on default seeds, so `cargo test` keeps working. The lab template fixes the exact names and the version.

Each lab adds its own pure functions over JSON strings, and one JSON representation of programs, `IR@1`, exported from Lean, links the labs.

## What a pass means (2 min)

A pass on n seeds is TESTED [T], with the generator's statistics, never PROVED. The same seed gives the same result in every browser. Each check ends one of three ways: a pass; a fail (a wrong result or a panic); or no verdict, because the module did not load, its version did not match, or the time limit ran out. No verdict, like `unknown`, refutes nothing.

For Rust readers: it is `cargo test` with the harness on the far side of a wasm boundary. You write the library, and the course writes the tests and draws their seeds. Where it breaks: you cannot see the seeds in advance, and your output reaches you only through each result's message.
