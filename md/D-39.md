# D-39 · UI code generation

> Draft: first-learner pass pending.

**Format.** Deferred drawer: always open, and it unlocks nothing.

**What it is.**

UI code generation means generating user-interface code from a specification.

**Why the roadmap defers it.**

The roadmap defers UI code generation until a concrete proof obligation or implementation demands it.

**What surfaces it.**

Surfaces in Today when a claim or a parked goal carries the topic `ui-codegen`, as a NOT COVERED [N] line can in your final report. The card then notes that nothing in the Core covers user interfaces.
