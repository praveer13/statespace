**Objective.** Discharge an obligation with your checker, replay every REFUTED [R] in the interpreter, and say what you record when a witness does not replay.

**Ideas taught.**

- Solver versus VC generator versus semantics: which correctness a result rests on

**Segments.**

1. Recall before you wire

## Recall before you wire (3 min)

Your checker asks one question per command: can a step from a state that meets your invariants end in a state that does not? A model from the solver is only a claim that such a step exists. The interpreter is what decides whether it does, and your Core now lets both disagree where an agent can see it.

**Question** (before the segment):

Your checker's result on an obligation is `sat`, and the witness you decode from the model does not replay in the interpreter. What do you record?

- A. REFUTED [R]: the solver found the violation.
- B. No stamp yet: open a doubt against both sides, and triage the encoding, the decoder and the VC generator.
- C. The interpreter is wrong, so keep the solver's verdict.

## Re-run your gate (6 min)

The Stage 4 gate asks one thing of your checker: every REFUTED [R] it reports replays in the interpreter (LAB-4.c5). The model decodes into a Mini-Plinth state, the command runs there, and only a violation that reproduces earns the stamp. A model that does not replay earns none. It is a defect in your generator, never a verdict about the command.

Two other results are not refutations either. A query that ends with no verdict fails closed, and the invariant is enforced at commit (run RUN-z3-unknown-pow). A satisfiable inductive step is not yet a bug, because its pre-state may be unreachable (S4.L6).

The cell is your checker in miniature, on a command that moves money between `a` and `b` and leaves `c` alone. It runs the query twice, once with the frame equation for `c` left out and once with it put back, and replays each model before it picks a stamp. Edit it and run it again.

**Cell 1** (INS-z3)

Query asserts: a state that meets the invariant and the guard, takes the transfer's step and leaves some account below zero. `sat` means the solver found a model. The replay decides what the model is worth.

```python
from z3 import *

def transfer(state, n):                          # the interpreter, in miniature
    if not (0 < n <= state['a']):
        return 'Err', state                      # a failed guard leaves the state alone
    return 'ok', {**state, 'a': state['a'] - n, 'b': state['b'] + n}    # c is untouched

def check(with_frame):
    a, b, c, n = Ints('a b c n')
    a2, b2, c2 = Ints('a2 b2 c2')
    premises = [a >= 0, b >= 0, c >= 0,          # Inv
                n > 0, n <= a,                   # the type of n, and the guard
                a2 == a - n, b2 == b + n]        # the step
    if with_frame:
        premises.append(c2 == c)                 # the frame: c is untouched
    s = Solver()
    s.add(*premises, Not(And(a2 >= 0, b2 >= 0, c2 >= 0)))
    verdict = s.check()
    print('with the frame:' if with_frame else 'without the frame:', verdict)
    if verdict == sat:                           # decode the model, then replay it
        m = s.model()
        val = lambda x: m.eval(x, model_completion=True).as_long()
        outcome, after = transfer({'a': val(a), 'b': val(b), 'c': val(c)}, val(n))
        if outcome == 'ok' and min(after.values()) < 0:
            return 'REFUTED [R]'
        return 'no stamp: the witness does not replay'
    if verdict == unsat:
        p = Solver()
        p.add(*premises)                         # the premise witness
        return 'PROVED [P]' if p.check() == sat else 'no stamp: the premises contradict'
    return 'UNKNOWN [?]'

print(check(with_frame=False))
print(check(with_frame=True))
```
