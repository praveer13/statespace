# S3.L9 · The unsafe command; goldens as theorems

> Draft: first-learner pass pending.

**Format.** Short lesson with reading, about 23 minutes.

**Objective.** Add force move and give a successful call that leaves the invariant, find a call that separates a faulty evaluator from the goldens, and say which check catches a redefined evaluator.

**Ideas taught.**

- Kernel-checked goldens as the correspondence check for learner-owned semantics
- An invariant preserved by every successful transition

**Segments.**

1. A question first
2. The unsafe command
3. Goldens as theorems
4. Exit

## The unsafe command (8 min)

So far every command kept the invariant. Add one that does not: `force move n from x to y`, a move with no cover requirement, so R-cover has nothing to say about it. Admit it as well-typed and a successful step can leave `Inv`.

That ends `step_preserves_inv` for the extended language. The reference states its negation as `cex_force`, and `decide` closes it (run RUN-lean-unsafe-cmd). A counterexample the kernel checked settles the matter, so do not hunt for a cleverer proof. Keep the broken command in `broken/`, beside a fix that removes `force move` or demands a covering guard.

## Goldens as theorems (9 min)

Comparator accepted your proof against the pinned statement. That checks the statement's text. The statement mentions your evaluator, `exec`, and you wrote it. Redefine `exec` to return `guardFailed` for every call and `step_preserves_inv` still holds, vacuously, because no call succeeds. Comparator checks against a challenge that copies your definitions, so it passes.

Goldens close the gap. A golden is a theorem, `theorem golden_k : exec p c s₀ = r := by decide`, whose right side comes from the reference. It is a theorem and not printed output because a closed `decide` proof adds no axiom, `native_decide` adds a `_native` one (run RUN-lean-axioms), and `#eval` can disagree with the kernel through `implemented_by` (run RUN-lean-implemented-by).

**Cell 2** (INS-bench-lean)

An evaluator redefined to reject every call, with one golden.

The recorded receipt runs two checks on this source: comparator against the pinned statement, and the goldens.

```lean
def exec (p : Program) (c : Call) (s : State) :
    Except Err (State × Output × List Effect) :=
  .error (.guardFailed c.name)

theorem golden_transfer_ok :
    exec refProgram transferCall s0 = .ok (s1, [], [.notify b]) := by
  decide
```
