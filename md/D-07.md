# D-07 · The Lean error museum

> Draft: first-learner pass pending.

**Format.** Drawer: side material, always open, about 12 minutes.

**Objective.** For a Lean message, say what it means and pick a first move, read the goal it leaves, and stamp an axiom list.

**Ideas taught.**

- Predict the goal a tactic produces
- What `omega`, `decide` and `grind` close, and which axioms they add
- Read `#print axioms`; standard, `sorryAx`, `_native`, custom; build versus replay

**Segments.**

1. Try first
2. Goals, automation and names
3. Trust and verdict lines
4. When the check did not run
5. Check yourself

## Goals, automation and names (3 min)

Each exhibit gives the message as recorded (its run sheet holds the exact text), what it means and its usual cause, a first move, the tempting wrong move and why not, and the lesson that teaches it. The first eight form the summary.

**1. Unsolved goals, with the goal printed** (run RUN-lean-ih-ungeneralised). The script ended with goals left, often because a hypothesis was too weak (it was not generalized) or because a case split left a branch. First move: read the remaining goal and ask which hypothesis would close it. Tempting wrong move: `sorry` "to see the rest". The build still passes with exit code 0 (run RUN-lean-axioms), but the claim then reads "PROVED modulo the assumed lemmas". Lesson S2.L7.

**2. `omega` reports a possible counterexample** (run RUN-lean-noguard). Values satisfy the hypotheses and violate the goal in linear arithmetic, so a hypothesis is missing (often the guard) or the goal is false. First move: check the values against your statement. Tempting wrong move: switch to `grind`. In manual mode the step is flagged as automated, `grind` adds `Classical.choice` to the axioms where `omega` does not (run RUN-lean-axioms), and a false goal stays false. Lesson S2.L6.

**3. A termination failure on a circular appeal** (run RUN-lean-s2-cells). The proof applies the theorem to the same argument, so nothing shrinks. First move: use the hypothesis for the smaller case. Tempting wrong move: assume termination away, which hides the circularity without removing it. Lesson S2.L4.

**4. An unknown identifier under `autoImplicit false`** (run RUN-lean-s2-cells). A name is not in scope: a typo or a missing binder. First move: declare the variable or fix the name. Tempting wrong move: turn `autoImplicit` on. Lean then binds the typo as a new variable and the statement changes silently, which is why the templates turn it off. Lesson S2.L2.

**5. `ℤ` not recognized** (run RUN-lean-s2-cells). `ℤ` is Mathlib notation, and core Lean writes `Int`. First move: write `Int`. Tempting wrong move: add Mathlib. A Mathlib project's packages take 7.3G (run RUN-lean-mathlib), and the course needs none. Lesson S2.L2.

## Trust and verdict lines (3 min)

**6. The warning that a declaration uses `sorry`**, with exit code 0 (run RUN-lean-axioms). The file built with a hole in it. First move: find each `sorry`; `#print axioms` lists `sorryAx`. Tempting wrong move: read a zero exit code as "proved". Lesson S2.L9.

**7. `lake check` rejects the axiom `sorryAx` and then says the kernel accepts the solution** (run RUN-lean-axioms). Two verdicts: the kernel accepted the terms, and the axiom policy rejected them. First move: read both lines; the receipt keeps both. Tempting wrong move: trust the kernel line alone. Lesson S2.L9.

**8. The comparator reports that your statement, or a definition it uses, does not match the pinned challenge** (run RUN-lean-comparator). First move: restore the pinned statement and prove that. Tempting wrong move: edit the challenge, whose hash then changes and voids the claim to UNKNOWN [?], with the reason statement mismatch. Lesson S2.L10.

**9. A decision tactic complains that the goal still has free variables**, with a hint to use `+revert` (run RUN-lean-comparator). First move: revert or generalize them, or split into cases. Tempting wrong move: reach for `native_decide`. It adds an axiom of its own and with it the compiler to the trusted base (run RUN-lean-axioms), and it still needs a closed goal. Lesson S2.L9.

## When the check did not run (3 min)

**10. The comparator exits with code 2 without bubblewrap, and with code 1 when bubblewrap cannot start under default Docker** (run RUN-lean-bwrap-docker). The check did not run: the sandbox failed, not your proof. First move: read the verdict lines, and use the devcontainer (D-15). Tempting wrong move: read the second exit code as a rejection. Lesson S2.L10.

**11. A proof of `False` built under `debug.skipKernelTC`**: a clean build, an axiom list that says the proof depends on none, and then kernel replay rejects it with a declaration type mismatch (run RUN-lean-skipkernel). The elaborator was told to skip the kernel. First move: let the kernel replay decide. Tempting wrong move: trust the build and the axiom list. Lesson S2.L9.

**12. Linter warnings**: a proposition declared with `def`, deprecations, unused variables, unused `simp` arguments (run RUN-lean-s2-cells). These are style and maintenance warnings, and the build passes. First move: follow the suggestion (`theorem` for a proof). Tempting wrong move: treat a warning as a failed proof. Lesson S2.L2.
