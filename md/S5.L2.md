## Run it twice (14 min)

**Question** (before the segment):

TLC stops with a deadlock report. What does that tell you?

- A. Two workers are waiting on each other's lock.
- B. The invariant holds, because TLC finished.
- C. Some reachable state enables no action of `Next`.

Here is the read-then-write transfer as a hand-written TLA+ spec. A worker's `Read` copies the balance into `seen` and decides from that copy whether it may write. Its `Write` later sets the balance to the copy minus the amount. `NoOverspend` says the account never pays out more than it started with. Run it on the Bench twice and read the raw output both times: the first line that names an error is the answer, and the counts and the trace follow it.

To read the syntax: `/\` is and, `\/` is or, `\E w \in Workers` is "for some worker", `x'` is the value of `x` in the next state, `UNCHANGED <<a, b>>` keeps both, and `[f EXCEPT ![w] = v]` is the function `f` with `w` mapped to `v`. The module is yours to edit after the first run.

PlusCal is pseudocode that translates into TLA+. The translator adds a `Terminating` action so that finishing is not reported as a deadlock (run RUN-pcal-doublespend), so the deadlock below belongs to the hand-written spec. Drawer D-09 shows the translation beside it.

**Cell 1** (INS-bench-tlc)

Model asserts: `NoOverspend` holds in every reachable state. This run uses TLC's default flags, so the deadlock check is on, and one worker.

```tla
---- MODULE DoubleSpend ----
EXTENDS Naturals
CONSTANTS Init, Amount, Workers
VARIABLES bal, pc, seen, spent
vars == <<bal, pc, seen, spent>>

Init_ == /\ bal = Init
         /\ pc = [w \in Workers |-> "read"]
         /\ seen = [w \in Workers |-> 0]
         /\ spent = 0

Read(w) == /\ pc[w] = "read"
           /\ seen' = [seen EXCEPT ![w] = bal]
           /\ pc' = [pc EXCEPT ![w] = IF bal >= Amount THEN "write" ELSE "done"]
           /\ UNCHANGED <<bal, spent>>

Write(w) == /\ pc[w] = "write"
            /\ bal' = seen[w] - Amount
            /\ spent' = spent + Amount
            /\ pc' = [pc EXCEPT ![w] = "done"]
            /\ UNCHANGED seen

Next == \E w \in Workers : Read(w) \/ Write(w)
Spec == Init_ /\ [][Next]_vars
NoOverspend == spent <= Init
====
\* CONSTANTS Init = 100, Amount = 80, Workers = {w1, w2}
\* INIT Init_, NEXT Next, INVARIANT NoOverspend
```
