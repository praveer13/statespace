## All worlds, and a hierarchy (10 min)

Hunt for a violation by asserting its negation, as in S1: some user reads a document of another tenant, and no share to the user or the user's teams explains it. Here `sat` is a distinguishing world. `unsat` counts only beside two witnesses: the premises hold together, and some read is allowed at all, because a policy that denies everything satisfies every confidentiality property.

**Cell 1** (INS-z3)

Query asserts: a cross-tenant read with no explicit share, under the policy alone. `sat` means such a world exists.

```python
from z3 import *

User, Team, Doc, Tenant = [DeclareSort(n) for n in ("User", "Team", "Doc", "Tenant")]
member     = Function("member", User, Team, BoolSort())
owns       = Function("owns", Team, Doc, BoolSort())
share_user = Function("share_user", Doc, User, BoolSort())
share_team = Function("share_team", Doc, Team, BoolSort())
revoked    = Function("revoked", Doc, User, BoolSort())
tenant_u   = Function("tenant_u", User, Tenant)   # a user's tenant
tenant_t   = Function("tenant_t", Team, Tenant)   # a team's tenant, and so its documents'

u, d, t1, t2 = Const("u", User), Const("d", Doc), Const("t1", Team), Const("t2", Team)

rule1 = And(member(u, t1), owns(t1, d))             # a member of the owning team t1
rule2 = And(share_user(d, u), Not(revoked(d, u)))   # shared with the user, not revoked
rule3 = And(member(u, t2), share_team(d, t2))       # shared with one of the user's teams
canread = Or(rule1, rule2, rule3)

# the violation: a read across tenants that no explicit share explains
violation = And(canread, Not(rule2), Not(rule3), tenant_u(u) != tenant_t(t1))

# WF1: a member belongs to the team's tenant
x, y = Const("x", User), Const("y", Team)
wf1 = ForAll([x, y], Implies(member(x, y), tenant_u(x) == tenant_t(y)))

def verdict(*facts):
    s = Solver()
    s.set("rlimit", 1000000)
    s.add(*facts)
    return s.check()

print("no invariants :", verdict(violation))
```

Teams nest, so a member belongs to every ancestor team too. Cedar's paper (section 4.3) describes three ways to give a solver that. Leave the hierarchy unconstrained, which admits a spurious violation that needs a cycle. State acyclicity and transitivity as quantified rules, which can make the encoding undecidable. Or ground the hierarchy as data and constrain only the teams the query mentions, its footprint.

**Cell 2** (INS-z3)

Query asserts: a user reaches a team of another tenant by membership or nesting. The cell prints a verdict for each encoding.

```python
from z3 import *

User, Team, Doc, Tenant = [DeclareSort(n) for n in ("User", "Team", "Doc", "Tenant")]
member   = Function("member", User, Team, BoolSort())
subteam  = Function("subteam", Team, Team, BoolSort())   # subteam(s, t): s is nested directly in t
nested   = Function("nested", Team, Team, BoolSort())    # nested at any depth
mid      = Function("mid", Team, Team, Team)             # a team between s and t
owns     = Function("owns", Team, Doc, BoolSort())
tenant_u = Function("tenant_u", User, Tenant)
tenant_t = Function("tenant_t", Team, Tenant)

u, x = Consts("u x", User)
s, m, t = Consts("s m t", Team)
d = Const("d", Doc)

wf1 = ForAll([x, t], Implies(member(x, t), tenant_u(x) == tenant_t(t)))
wf2 = ForAll([s, t], Implies(subteam(s, t), tenant_t(s) == tenant_t(t)))

# nested is the transitive closure of subteam, written as quantified rules
closure = [
    ForAll([s, t], Implies(subteam(s, t), nested(s, t))),
    ForAll([s, m, t], Implies(And(nested(s, m), nested(m, t)), nested(s, t))),
    ForAll([s, t], Implies(nested(s, t), Or(subteam(s, t), And(nested(s, mid(s, t)), nested(mid(s, t), t))))),
]
acyclic = ForAll([t], Not(nested(t, t)))                 # WF3: no team nests in itself

# the violation: u reaches team t by membership or nesting, t owns d, and the tenants differ
reach = Or(member(u, t), Exists([s], And(member(u, s), nested(s, t))))
violation = And(reach, owns(t, d), tenant_u(u) != tenant_t(t))

def verdict(*facts):
    sv = Solver()
    sv.set("rlimit", 1000000)
    sv.add(*facts)
    r = sv.check()
    return str(r) + (" (" + sv.reason_unknown() + ")" if r == unknown else "")

print("unconstrained:", verdict(wf1, wf2, *closure, violation))
print("quantified   :", verdict(wf1, wf2, *closure, acyclic, violation))

# grounded: the hierarchy is data. Only the teams the query mentions get constraints,
# and nesting runs two levels deep.
T = [Const("t%d" % i, Team) for i in range(3)]
def in_team(user, team):
    return Or(member(user, team),
              *[And(member(user, a), subteam(a, team)) for a in T],
              *[And(member(user, a), subteam(a, b), subteam(b, team)) for a in T for b in T])
g_wf1 = And(*[Implies(member(u, a), tenant_u(u) == tenant_t(a)) for a in T])
g_wf2 = And(*[Implies(subteam(a, b), tenant_t(a) == tenant_t(b)) for a in T for b in T])
g_violation = Or(*[And(in_team(u, a), owns(a, d), tenant_u(u) != tenant_t(a)) for a in T])
print("grounded     :", verdict(g_wf1, g_wf2, g_violation))
```

## Within a scope (8 min)

A bounded check lists every world inside a stated scope and runs the policy on each. Jackson's small scope hypothesis says that many bugs have small counterexamples, so it finds many of them. The scope here is eight worlds: two teams, two tenants, one user, one document, and the user's team nested in the document's team or not.

**Cell 3** (INS-datalog)

Query asks: which worlds have a cross-tenant read (`violation`), and which break WF2 (`wf2_broken`)?

```datalog
.decl world(w: symbol, a1: symbol, a2: symbol, nested: symbol)
.decl tenant_of_team(w: symbol, t: symbol, a: symbol)
.decl tenant_of_user(w: symbol, u: symbol, a: symbol)
.decl member(w: symbol, u: symbol, t: symbol)
.decl owns(w: symbol, t: symbol, d: symbol)
.decl subteam(w: symbol, s: symbol, t: symbol)
.decl inteam(w: symbol, u: symbol, t: symbol)
.decl canread(w: symbol, u: symbol, d: symbol)
.decl violation(w: symbol)
.decl wf2_broken(w: symbol)
.output violation
.output wf2_broken

// the scope: two teams, two tenants, one user in t1, one document owned by t2,
// and t1 nested in t2 or not. Every such world is one row.
world("w1", "acme", "acme", "no").    world("w2", "acme", "acme", "yes").
world("w3", "acme", "birch", "no").   world("w4", "acme", "birch", "yes").
world("w5", "birch", "acme", "no").   world("w6", "birch", "acme", "yes").
world("w7", "birch", "birch", "no").  world("w8", "birch", "birch", "yes").

// each world's facts
tenant_of_team(w, "t1", a) :- world(w, a, _, _).
tenant_of_team(w, "t2", a) :- world(w, _, a, _).
tenant_of_user(w, "u", a) :- world(w, a, _, _).
member(w, "u", "t1") :- world(w, _, _, _).
owns(w, "t2", "d") :- world(w, _, _, _).
subteam(w, "t1", "t2") :- world(w, _, _, "yes").

// the policy: rule 1 with nesting (the worlds hold no shares)
inteam(w, u, t) :- member(w, u, t).
inteam(w, u, t) :- inteam(w, u, s), subteam(w, s, t).
canread(w, u, d) :- inteam(w, u, t), owns(w, t, d).

// a violation: a read across tenants
violation(w) :- canread(w, u, d), tenant_of_user(w, u, a), owns(w, t, d), tenant_of_team(w, t, b), a != b.
// WF2: a subteam belongs to its parent's tenant
wf2_broken(w) :- subteam(w, s, t), tenant_of_team(w, s, a), tenant_of_team(w, t, b), a != b.
```
