## Before the compiler (3 min)

Your compiler needs somewhere to compile to. The IR here is small: reads, writes, asserts and aborts, one transaction's worth. Its semantics and your compiler are LAB-9.3. First, what a careless scheme does to money.

**Question** (before the segment):

`move balance(a) from a to b`, with a = 5 and b = 0. A compiler debits a by balance(a), then credits b by balance(a), reading balance(a) a second time for the credit. What does b end with?

- A. 5
- B. 0
- C. 10

## Semantics, then a scheme (13 min)

The IR has seven instructions. `ldi` loads a constant, `read` loads a balance, `arith` computes, and `write` stores a balance. `assertGe` aborts with an error unless one register is at least another, and `abort` aborts outright. `writeIf` writes only when its condition holds, like an UPDATE whose WHERE matches no row, with the rowcount ignored. A run ends committed with a store, or aborted with an error, and an abort discards every write of the run, as a ROLLBACK does.

`exec` is a function: one program and one starting state give one outcome. State that anyway, as `exec_deterministic`. Forward simulation needs it (S9.L5), and a database under concurrency does not meet it. LLVM's IR is not deterministic (`undef`), so Alive2 checks refinement instead of equality.

The compile scheme makes two decisions. The amount is computed once, before the first write, and saved in a register. The credit reads the store the debit left, so a self-transfer nets to zero.

| Source | IR |
|---|---|
| `require e₁ e₂ err` | `e₁` into `r0`, `e₂` into `r1`, then `assertGe r0 r1 err` |
| `move amt src dst` | `amt` into `r0`; `read r1 src`; `sub r1 r1 r0`; `write src r1`; `read r1 dst`; `add r1 r1 r0`; `write dst r1` |
| `seq c₁ c₂` | the code for `c₁`, then the code for `c₂` |
| `abort err` | `abort err` |

**Cell 1** (INS-interp)

Each program runs from the store above. The view shows what a client observes: committed with a store, or aborted with an error and the store the client sees.

```text
store (a0, a1) = (5, 0)

program 1
  ldi      r0 9
  write    a0 r0
  abort    denied

program 2
  ldi      r0 1
  ldi      r1 2
  assertGe r0 r1 insufficient
  ldi      r2 9
  write    a0 r2

program 3
  ldi      r0 1
  ldi      r1 2
  ldi      r2 9
  writeIf  r0 r1 a0 r2
```
