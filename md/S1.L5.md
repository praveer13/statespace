## The sender at 64 bits (13 min)

Over `Int`, a balance never overflows. The 64-bit encoding is `BitVec(64)`: its `<`, `<=` and `-` are signed, and its arithmetic wraps around at 2⁶⁴. Take the guard `X <= A` and leave out the premise `X > 0`. Then ask whether the sender can end below zero.

**Cell 1** (INS-z3)

Query asserts: 64-bit balances and an amount that pass the guard, with no requirement that the amount be positive, and a sender who ends below zero. `sat` means one exists.

```python
from z3 import *
A, B, X = BitVecs('A B X', 64)      # 64-bit balances and amount
s = Solver()
s.add(A >= 0, B >= 0, X <= A)       # the guard, with no X > 0
s.add(A - X < 0)                    # the sender ends below zero
print(s.check())
print(s.model())
```

## The total at 64 bits (13 min)

Conservation over 64 bits is the next question. Subtracting from one balance and adding to the other wrap in opposite ways, so the total may still hold.

**Cell 2** (INS-z3)

Query asserts: whatever leaves the sender arrives at the recipient, with every operation wrapping at 2⁶⁴. `prove` prints `proved` when no counterexample exists.

```python
from z3 import *
A, B, X = BitVecs('A B X', 64)
prove((A - X) + (B + X) == A + B)   # conservation, modulo 2**64
```

## Two readings of the same bits (13 min)

A bit-vector has no sign of its own. Each operator reads the bits one way: `<`, `<=` and `-` are signed, and `ULT`, `ULE` and `UGT` are unsigned. A guard and a property that read the same bits differently disagree about the state.

**Cell 3** (INS-z3)

Query asserts: a guard written with unsigned comparisons, and a sender who ends below zero when read as signed. `sat` means one exists.

```python
from z3 import *
A, X = BitVecs('A X', 64)
s = Solver()
s.add(UGT(X, 0), ULE(X, A))         # the guard reads the bits as unsigned
s.add(A - X < 0)                    # the property reads them as signed
print(s.check())
print(s.model())
```

Here is what "64-bit" means across the tools you will meet.

| Semantics | An overflowing credit | Evidence |
|---|---|---|
| Lean `Int` | cannot overflow: arbitrary precision | the definition of the type |
