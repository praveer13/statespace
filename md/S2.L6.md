## Which fact serves which branch (14 min)

**Question** (before the segment):

`grind` and `omega` each close `transfer_conserves`. Do the two proofs depend on the same axioms?

- A. Yes: a theorem has one axiom list.
- B. No: the `grind` proof adds `Classical.choice`.
- C. Neither depends on any axiom.
- D. Both add `sorryAx`.

A transfer proof splits in two. In the allowed branch the guard holds, the balances change, and the proof does arithmetic. In the rejected branch the guard fails and the transfer hands back the state it was given. That second branch has a fixed shape: every rejection theorem has one hypothesis, that the guard fails, and one conclusion, that nothing changed.

```lean
theorem transferPos_rejected (s : Ledger) (n : Int) (h : ¬ (0 < n ∧ n ≤ s.a)) :
    transferPos s n = s
```

`transferPos` is the transfer from earlier in this stage with a stricter guard: it also rejects a zero amount. It runs parallel to the transfer in LAB-2, so the proof below uses the moves you will need there without being a proof you will write. Read it as a manual proof, and watch which line uses which fact.

**Cell 1** (INS-goal-replay)

Replay shows: the proof one tactic at a time with the goal after each, then the axioms the finished proof depends on. No tactic in it is automation.

```lean
structure Ledger where
  a : Int
  b : Int
deriving Repr, DecidableEq

def transferPos (s : Ledger) (n : Int) : Ledger :=
  if 0 < n ∧ n ≤ s.a then { a := s.a - n, b := s.b + n } else s

theorem transferPos_nonneg (s : Ledger) (n : Int) (ha : 0 ≤ s.a) (hb : 0 ≤ s.b) :
    0 ≤ (transferPos s n).a ∧ 0 ≤ (transferPos s n).b := by
  unfold transferPos
  split
  · next hg => exact ⟨Int.sub_nonneg_of_le hg.2, Int.add_nonneg hb (Int.le_of_lt hg.1)⟩
  · exact ⟨ha, hb⟩

#print axioms transferPos_nonneg
```
