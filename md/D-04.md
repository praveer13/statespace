## A state is a function, a step is a relation (3 min)

A state maps names to values: for two accounts, S = (a, b); for many, `bal : Acct → Int`. A property of one state is a set of states: "a ≥ 0" picks the states in which the sender is non-negative.

A step is a set of pairs (S, S′), written with primed variables. A transfer of `amt` is `amt > 0 ∧ amt ≤ a ∧ a′ = a − amt ∧ b′ = b + amt`. A relation may allow no successor (the guard fails, so there is no pair) or several (a choice of amount). Whatever it does not mention is unconstrained: with a third account c, the relation must say `c′ = c`. That conjunct is a frame condition, and lesson S4.L5 returns to it with a missing frame that "proves" a false theorem (run RUN-z3-missing-frame).

## Properties of steps (2 min)

Conservation, `a′ + b′ = a + b`, is a property of pairs. Over `Int` it holds with no guard at all (run RUN-z3-conservation-noguard), so a step property can hold while a state property, non-negativity, fails. A chain S → S′ → S″ checks two steps, as the double capture does (run RUN-z3-double-capture).

With many accounts, the new balances are `bal′ = upd(upd(bal, f, bal f − n), t, bal t + n)`. When f = t, computing both new balances from the old state mints money: Z3 finds a model [n = 1, t = 0, f = 0] (run RUN-z3-selftransfer), and in Lean the buggy transfer ends with more money than it started with while the fixed one does not (run RUN-lean-selftransfer) (lesson S2.L8).

## Reading a two-state counterexample (1 min)

Read the pre-state, the step's parameters and the post-state, and evaluate each conjunct of the property on the pair: the failing conjunct names the bug. Then ask which class of pairs fails (D-01), and whether the pre-state can occur at all, a question lesson S4.L6 makes precise (D-05).

For Rust readers: `fn step(s: &State, c: Cmd) -> Option<State>` is a relation that happens to be a partial function, and in-place updates through `&mut` alias exactly as the self-transfer does. Where it breaks: a relation can allow several successors while a Rust function returns one. A specification says what is allowed, and the code picks.
