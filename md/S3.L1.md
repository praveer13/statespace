## A question first (3 min)

Stage 3 gives Mini-Plinth a meaning of its own, independent of SQL, Rust and any screen. The roadmap's toy syntax is `entity Account; command Transfer(from, to, amount); requires balance(from) >= amount; do move amount from from to to.` You will give programs like this a meaning without ever parsing them.

**Question** (before the segment):

You skip parsing and build programs directly as AST values. Which problem can such a value never have?

- A. A missing closing parenthesis.
- B. An amount used where an account is expected.
- C. Two commands with the same name.
- D. A guard that is never true.

## Programs as trees (9 min)

A parser turns text into a tree, and the semantics only reads the tree. Parsing adds no meaning, so you build the tree directly, as a Lean value. The Rust front end you write later parses the roadmap's text into this same tree.

Each kind of thing in Mini-Plinth is an inductive type: a closed list of the ways to make one.

```lean
inductive Ty where
  | account | amount | hold | int | bool

inductive Expr where
  | lit     : Int → Expr
  | var     : String → Expr
  | balance : Expr → Expr
  | frozen  : Expr → Expr
  | add     : Expr → Expr → Expr
  | sub     : Expr → Expr → Expr
  | ge      : Expr → Expr → Expr
  | eq      : Expr → Expr → Expr
  | and     : Expr → Expr → Expr
  | not     : Expr → Expr

inductive ResourceOp where
  | deposit : Expr → Expr → ResourceOp          -- deposit n to a
  | move    : Expr → Expr → Expr → ResourceOp   -- move n from x to y
  | hold    : Expr → Expr → ResourceOp          -- hold n on x
  | capture : Expr → Expr → ResourceOp          -- capture h to y
  | release : Expr → ResourceOp                 -- release h

inductive Stmt where
  | op  : ResourceOp → Stmt
  | set : String → Expr → Expr → Stmt           -- set f(x) := e

structure Cmd where
  name   : String
  params : List (String × Ty)
  guard  : Expr
  body   : Stmt
```

Lean checks the shape of what you build: `move` takes exactly three expressions, so a `move` with two is not a value. Mini-Plinth's own types, such as "this is an account", are a separate judgment, which you write next lesson.

## Shape is not meaning (8 min)

A type index on `Expr` could make Lean reject `balance(amount)` itself, but then you could not see which Mini-Plinth rule fired. This course keeps the tree plain and writes the typing rules, so every rejection names its rule.
