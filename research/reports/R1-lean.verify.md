# R1-lean verification log

Verifier: independent fact-check pass, run 2026-10-21 (UTC). Methods: GitHub REST API via `gh` (read-only), curl of primary HTML pages with verbatim grep (not a summarising fetcher), WebFetch for arXiv and GitHub Docs, and re-running the report's own Lean 4.35.0 measurement files with the locally installed toolchain.

Overall: the report is unusually accurate. Every load-bearing quote I checked exists verbatim. The corrections are small: a few release dates are off by one or two days, the release count is miscounted, the list of point releases is incomplete, one quote is attributed to the PR description when it is in a commit message, and the 4.34 "three kernel issues" were two kernel issues and one runtime issue.
