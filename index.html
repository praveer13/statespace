Pyodide and Z3 on this device

This page measures how the course's in-browser solver behaves on your device: how big the first download is, how long it takes to be ready, how long a solver budget (rlimit) takes, how much memory the engine claims, and whether the browser still has the download the next time you come back. Nothing leaves your device until you copy the report yourself.

Before you start

  • The first run downloads the engine. Its size appears here once the page has connected. Use Wi-Fi unless you mean to test a mobile connection.
  • Use a normal tab, not a private one: a private tab forgets everything when it closes, so every return visit would look like a first visit.
  • Close other tabs and apps. Turn off battery saver.
  • Keep the screen on and this tab in front until the status line says the session is done. The log at the bottom shows each step.
