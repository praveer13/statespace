## Implication and the rules built from it {minutes=3}

| P | Q | P → Q |
|---|---|---|
| true | true | true |
| true | false | false |
| false | true | true |
| false | false | true |

An implication is broken only by a case where the premise holds and the conclusion fails.

A rule is an implication. "Every allowed transfer leaves the sender at zero or above" says: for every input, if the transfer is allowed, the sender ends at zero or above. A transfer that is not allowed cannot break it, which is why the violation query keeps `allowed` and negates only the conclusion (D-03). Reading if-then as "and" would make the rule false the moment any transfer is rejected.

## Vacuity {minutes=2}

If no input satisfies the premises, every property about them is "proved". Give a transfer a maximum of zero beside `amount > 0 ∧ amount ≤ MAX_TRANSFER`, and the violation query, an absurd property such as "the sender ends a million richer" and the premises alone all come back `unsat` {{run:RUN-z3-vacuous-unsat}}.

The tell is the premise query: the premises and the guard, without the negated property. It must come back `sat`, and its model is the premise witness. Every claim built on an `unsat` carries one in its method field.

## Precedence {minutes=1}

→ binds more weakly than ∧: `a ∧ b → c` reads `(a ∧ b) → c`, and an unparenthesized chain can say something you did not mean. PutnamBench, a public set of formal competition problems, has had issues of this kind: a readability refactor lost parentheses, so → swallowed a chain of ∧ and the hypotheses became inconsistent, which left the statement vacuous. Parenthesize whenever you move a clause.

For Rust readers: `if guard { assert!(post) }` passes on every input where the guard is false, so a suite whose inputs never satisfy the guard stays green. The comparison breaks here: the `if` runs on the inputs a test supplies, while an implication is a claim about every input, and the premise query asks whether any input satisfies the guard at all. In Lean, `P → Q` is a function type, a way to turn evidence for P into evidence for Q (lesson S2.L2).
