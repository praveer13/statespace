## Labels are atomic steps {minutes=3}

Code between two labels runs as one TLA+ action. The translator adds a program counter and one action per label, so more labels mean finer steps and more interleavings.

In the course's model M1 each worker has a read label and a write label, so two actions per worker. Merging them under one label makes the critical step atomic, which is the fix in lesson S5.L3. The course's own translation of M1, and its default-flags verdict, are recorded in {{run:RUN-pcal-doublespend}}.

## Finishing, deadlock and flags {minutes=3}

For hand-written TLA+, TLC's default flags make it report a deadlock when no action of Next is enabled. On DoubleSpend that message comes before the invariant violation, and with the `-deadlock` flag TLC reports the invariant violation instead {{run:RUN-tlc-doublespend}}. TLC's own help says of that flag: "{{run:RUN-tlc-help#values.deadlock_flag}}" {{run:RUN-tlc-help}}. The flag turns the deadlock check off and never on.

The PlusCal translator adds a terminating step when every process is done, so finishing is not reported as a deadlock. That is why this trap belongs to hand-written specs.

## Reading a TLC trace {minutes=1}

A trace lists states, and each step between two states is one action. The DoubleSpend counterexample has {{run:RUN-tlc-doublespend#values.deadlock_off.trace_states}} states and {{run:RUN-tlc-doublespend#values.deadlock_off.trace_actions}} actions: both workers read before either writes {{run:RUN-tlc-doublespend}}. Count length in actions, and say which unit you used.

## Why the course runs TLA+ {minutes=1}

The course's in-page checker reads TLA+ only, so PlusCal is translated when the page is built. PlusCal's fairness keywords become fairness conjuncts in the translation, and lesson S5.L7 writes fairness in TLA+ directly.

For Rust readers: a label is like the span between two `.await` points on a single-threaded executor. Inside it nothing else of yours runs, and at each label another task may. Where it breaks: an executor picks one schedule, while TLC explores every schedule the spec allows.
